<b>Challenge:</b> using open source imaging and sensor data to identify environmental disasters and anomalies.  

<b>Problem:</b>
Fire records don’t capture every fire. Small, remote, or short-lived fires can go unreported, leaving gaps in our understanding of environmental damage. We wanted to explore how satellite data could help uncover these overlooked events. 

<b>Solution: Ada's Eye!</b>
Ada’s-Eye compares NASA FIRMS satellite fire detections with independently reported fire brigade records to identify under-reported fires. Using statistical anomaly detection and spatiotemporal analysis, we identified satellite detections that resemble known fires but have no corresponding fire brigade record. To make Ada’s-Eye more engaging, we built a gamified globe where users can explore fire detections, guess which ones are anomalies, and earn points for spotting them correctly.
